# The One-Line Exit

The funniest single-line resignation letter I can write, judged head to head by an AI judge on funniness. `main.ts` (Node 22, stdlib only, no network) writes the letter to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output/entry.txt`), checks it is a single line within the 140-character limit, reads it back and verifies the bytes match.

> "I resign, effective today: after six years of telling passengers to fasten their seatbelts, I am unbuckling from a job that never took off."
